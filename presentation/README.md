# Earlier synthetic presentation

`Atlas_Academic_Defense.pptx` and `evidence.json` describe the earlier synthetic
research milestone. The current 2 November evaluation is notebook 03 and its
executed HTML under `reports/`.

`build_deck.mjs` requires the Codex-provided `@oai/artifact-tool` runtime;
`build_live.js` requires an active Codex artifact session. Neither is a standalone
npm/uv project or a prerequisite for replaying the analysis. The sources are kept
for provenance, with machine-specific file paths removed. Generated deck previews
belong in ignored `.build/`.
