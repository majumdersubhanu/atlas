# Atlas analyst workstation

Design direction: Bloomberg-inspired information density, Palantir-inspired object/relationship investigation, and Linear-inspired navigation clarity. These are design interpretations, not claims of reproducing those products.

UI Skills used: anthropics/frontend-design and ibelick/baseline-ui.

Palette: canvas #111214, panel #18191d, divider #303137, primary text #d7d8db, secondary text #a0a0aa, action amber #e4b16a. Failures retain a muted red semantic signal.

Layout: compact application bar → workspace actions → persistent scenario panel, central canvas and ledger tabs, institution inspector → playback and outcome strip. No marketing hero. Bank accounts and loan events are the product's primary objects.

Interaction: Ctrl/Cmd+K opens a Radix command dialog. Institution rows select the same bank as the graph. Matrix/ledger stay adjacent to the network view. Destructive changes use explicit confirmation. Network creation and scenario execution remain distinct actions.

References consulted: https://linear.app/docs/projects , https://www.palantir.com/docs/foundry/platform-overview/overview/index.html , https://data.bloomberglp.com/professional/sites/10/Fact-Sheet-Terminal-Connect.pdf .
